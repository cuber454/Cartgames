# Карточные игры (Android, доступные для незрячих)

Приложение с карточными играми, в которое можно играть на слух: озвучка
каждого события, TalkBack, жесты, звук и вибрация. Интерфейс — общий для
всех игр, сами игры добавляются по шаблону.

## Что уже есть

- `app/` — Android-модуль на Kotlin + Jetpack Compose: экран стола, меню,
  настройки, озвучка, жесты. Игр четыре — «Тысяча», «Дурак», «Козёл» и
  «101»; экран, речь и настройки у них общие, игра добавляется по шаблону.
- `engine/` — движок игр: карты, колода и правила всех четырёх игр. Чистая
  логика, без Android.
- Тесты: `engine/src/test/kotlin/...` — правила игр, `app/src/test/...` —
  настройки, фразы и разбор файла обновления.
- Сборка и выпуск через GitHub Actions (`.github/workflows/ci.yml`): тесты на
  каждую правку, черновой APK на pull request, подписанная сборка — на push
  в main. Приложение находит обновление само по `update.txt`.

## Что появится дальше

- Второй движок — для пасьянсов (одиночные раскладки). «Очко» отложено.
- «Козёл» вчетвером парами (`KOZEL.md`, 7.1).

## Как запускать тесты

Локально (нужны JDK 17 и Gradle):

    gradle :engine:test

В облаке — автоматически на каждую правку, см. `.github/workflows/ci.yml`:
там же собирается модуль `app`, которому нужен Android SDK.

## Документы проекта

- `CONCEPT.md` — общая концепция.
- `SPEC.md` — подробное ТЗ.
- `GAMES.md` — список игр-кандидатов по группам механик.
- `THOUSAND.md` — «Тысяча»: правила по книге, экран, алгоритм бота.
- `KOZEL.md` — «Козёл»: правила, экран, алгоритм бота.
- `HUNDRED_ONE.md` — «101» («Мавр»): правила, экран, речь.
- `SETTINGS.md` — настройки: общий слой и игровой, как их описывает игра.
