# Карточные игры (Android, доступные для незрячих)

Приложение с карточными играми, в которое можно играть на слух: озвучка
каждого события, TalkBack, жесты, звук и вибрация. Интерфейс — общий для
всех игр, сами игры добавляются по шаблону.

## Что уже есть

- `engine/` — движок игр: карты, колода, правила «Дурака» (подкидной,
  36 карт, двое). Чистая логика, без Android.
- Тесты движка: `engine/src/test/kotlin/...`

## Что появится дальше

- `app/` — Android-модуль на Kotlin + Jetpack Compose (экран стола, меню,
  настройки, озвучка, жесты).
- Второй движок — для пасьянсов (одиночные раскладки).
- Сборка APK через GitHub Actions.

## Как запускать тесты

Локально (нужны JDK 17 и Gradle):

    gradle :engine:test

В облаке — автоматически на каждый push, см. `.github/workflows/ci.yml`.

## Документы проекта

- `CONCEPT.md` — общая концепция.
- `SPEC.md` — подробное ТЗ.
- `GAMES.md` — список игр-кандидатов по группам механик.
- `THOUSAND.md` — «Тысяча»: правила по книге, экран, алгоритм бота.
- `SETTINGS.md` — настройки: общий слой и игровой, как их описывает игра.
